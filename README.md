# Morfologia Bucomaxilofacial II — Jogo Educacional

Projeto de monitoria interdisciplinar desenvolvido na **Universidade de Fortaleza (UNIFOR)**.

## 🎮 Como jogar

Acesse pelo GitHub Pages: `https://<seu-usuario>.github.io/<nome-do-repo>`

## 📋 Fases

| Fase | Conteúdo |
|------|----------|
| 01 | Trígono Carotídeo — identificar a região e músculos delimitadores |
| 02 | Quebra-cabeça da Carótida — montar a árvore vascular |
| 03 | Ramos Colaterais — identificar subdivisões da carótida externa |
| 04 | Áreas de Irrigação — mini game "complete a frase" |

## 🚀 Deploy no GitHub Pages

1. Faça upload dos arquivos (`index.html`, `style.css`, `game.js`) na raiz do repositório
2. Vá em **Settings → Pages**
3. Em **Source**, selecione a branch `main` e pasta `/root`
4. Salve — o site estará disponível em instantes
